# Figures

Authoritative figures are in `final-20261021-r1/`, generated by `scripts/plot.py` from actual stored result CSVs.

- 01: processing workflow and coverage.
- 02_03: three actual selected pair position/gap/TTC cases; selection rules are recorded in results.
- 04: ≥3-frame event counts at each threshold.
- 05: finite-TTC empirical distribution, displayed only over 0–30 seconds.
- 06: low-frame Jaccard matrices.
- 07: observed invalid net gaps, excluded from TTC.

Case TTC plots show 0–6 seconds for readability; numerical calculations are not truncated. No trajectory or event is fabricated. Full local case CSVs are rebuilt from source but excluded from publication because they retain original position columns.
